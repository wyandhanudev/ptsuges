## 🚀 Cara Penggunaan

1. Ekstrak semua file ke folder yang sama
2. Buka `index.html` di browser
3. Atau gunakan live server:
   - Klik kanan pada `index.html`
   - Pilih "Open with Live Server" (jika sudah install extension)

## ✏️ Cara Customization

### Mengubah Informasi Perusahaan
1. Buka `index.html`
2. Ubah teks di:
   - Logo text di navbar
   - Informasi kontak di section contact
   - Alamat, telepon, email

### Mengubah Warna (Color Scheme)
1. Buka `style.css`
2. Cari section `:root` di awal file
3. Ubah variable colors sesuai kebutuhan

### Menambah Portfolio/Project
1. Buka `index.html`
2. Cari section `<!-- PORTFOLIO SECTION -->`
3. Copy salah satu `.portfolio-card` div
4. Ubah isi sesuai project baru
5. Update icon, nama, deskripsi, dan tech stack

### Menambah Layanan
1. Buka `index.html`
2. Cari section `<!-- SERVICES SECTION -->`
3. Copy salah satu `.service-card` div
4. Ubah isi sesuai layanan baru
